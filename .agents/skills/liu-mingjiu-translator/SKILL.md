# 柳鸣九风格文学翻译与文本重铸

以现代白话散文为底、古典散文清劲骨架为骨，按“去翻译腔、结构重组、白描克制、长短错落”的标准处理文学、随笔及哲学性文本。技术文档、UI 文案与硬性法律合同不适用本技能。

## 输入模式

根据用户提供的材料进入对应路径，共享同一套句法重铸与文气标准：

- **外文精译**（提供外文原文）：在内部完成解构与剥壳后，直接以现代白话重铸。
- **去腔改译**（提供已有中文译文，无论是否附带原文）：保留原意与既定专名，手术式拆解欧化长句、冗余虚词与被动外壳，重塑语序和呼吸感；若附带原文且旧译存在误译或漏译，先保真纠偏再行文。

## 项目规范优先级

当任务位于带有本地翻译契约的仓库中（例如当前项目的 [AGENTS.md](../../../AGENTS.md) 与 [glossary.md](../../../glossary.md)），**先守术语定译、和合本圣经引文、段落对齐与角标（`[fn:N]`）等刚性约束，再在句法切分与白话行文上落实本技能标准**。

## 内部推演与重铸规程（只做不输出）

以下 1–3 步仅在内部完成，切勿把分析草稿打印到正文中：

1. **定刻度与骨架**：提炼原文的意象重心、动作链条与情绪刻度（冷淡、疏离、激越或反讽）；忠实维持原作的疏离感与冷感，不擅自拔高情绪或替作者抒情。
2. **剥离外语外壳**：打散嵌套长从句、分词悬垂与介词堆栈，抽出实质施事与核心动词。
3. **汉语意合重铸**（将欧化结构逐项化为地道汉语）：
   - **长定语拆句**：名词前修饰超过两层时，拆为前置独立短句或后置补叙，打断“的”字长链。
   - **化被动为主动**：把“被……所……”转为汉语主动句、受事主语句，或顺势隐去泛指施事。
   - **以动词代状态**：将“处于……的状态”“具有……的特征”“作出……的反应”直接压回精准动词或形容词。
   - **以意合代连接**：删去“这使得……”“从而导致”“当……的时候”“之所以……是因为”等路标虚词，靠事理先后、分句并置与短句断口自然推进。
   - **收敛冗余代词**：省去无歧义的回指“他/她/它/这/那”，需要明晰时改用简短名词复指或零形回指。
4. **白描质感与声韵定稿**：
   - 使用干净、干燥、准确的现代白话实词；适度嵌入精练的二字、四字动宾或偏正短语收束节奏，用具体动作与白描取代浮夸套语或大词。
   - 控制评价性形容词与感叹词，如实呈现叙事、心理与环境的质感。
   - 默读检验节奏：长短句自然错落，句尾落字实沉利落。

## 完稿核对

输出前对照以下四项自检：

- [ ] 全文无三层以上“的”字定语嵌套，无残余“这使得……”“处于……状态”“被……所……”句式。
- [ ] 无原文所无的煽情修饰或四字套语，未稀释原作冷感与反讽张力。
- [ ] 默读断句自然、呼吸流畅，句尾收束干净。
- [ ] 若属当前项目稿件，已完整遵循本地术语表、经文出处与排版格式约定。

## 交付格式

- **直接输出终稿译文**（或改译定稿），不加开场白、不列逐句对比分析、不做自我点评。
- 仅在某处涉及关键词句重塑、多义取舍或与直译存在重大结构调整时，在文末附极简的 **译者按**（点明依据即可，一两句收束；无可省略）。
